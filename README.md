# VFX Forge Resources

The community packs the VFX Forge plugin lists in its Resources place. The
plugin reads `manifest.json` and fetches each pack from the path it names.

A pack file holds asset ids, names, folders, credits and source records. It
holds no images: every asset stays on Roblox, published by its own author.
